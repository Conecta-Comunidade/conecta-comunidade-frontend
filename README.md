# ConectaComunidade Frontend

## Sobre

O **ConectaComunidade** é uma plataforma que conecta pessoas que precisam de serviços a pessoas que oferecem suas habilidades, facilitando a divulgação, busca e agendamento de serviços na comunidade.

### Primeira Entrega

Nesta primeira entrega do **ConectaComunidade**, foram desenvolvidas as principais telas da aplicação, incluindo:

- **Login**
- **Cadastro**
- **Página Inicial**
- **Perfil**
- **Agendamentos**
- **Buscar Serviços**
- **Criar Serviço**

Para acessar as telas, basta executar o projeto e utilizar as respectivas rotas no navegador:

- `/` → Login
- `/cadastro` → Cadastro
- `/home` → Página Inicial
- `/perfil` → Perfil
- `/agendamentos` → Agendamentos
- `/buscar-servicos` → Buscar Serviços
- `/criar-servico` → Criar Serviço

Nesta etapa, o foco foi desenvolver a estrutura visual e a navegação entre as principais páginas do sistema.
